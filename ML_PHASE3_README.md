## 3. Human-in-the-Loop (HITL) Design

The system no longer treats all data equally. In `models/feature_engineering.py`, we introduced a **Sample Weighting** logic:
1.  **Heuristic Data:** Assigned a weight of `1.0`. It provides the baseline "validity" rules.
2.  **Implicit Feedback:** (e.g., when you export a schedule) Assigned a weight of `2.0`.
3.  **Explicit Feedback:** (e.g., when you give a 5-star rating in Streamlit) Assigned a weight of `5.0`.

**Result:** The model will "unlearn" heuristic rules if they consistently conflict with human preferences.

## 4. Integration Guide (For Streamlit)

To display the AI-predicted score in the dashboard, use the following logic. You don't need to worry about the math; just pass the DataFrame.

### How to Predict Scores
```python
import pandas as pd
import joblib
from models.feature_engineering import preprocess_data

# 1. Load the artifacts
model = joblib.load('models/optiplua_model.pkl')

def get_ai_score(df_new_schedule):
    """
    Takes a schedule DataFrame (same format as raw_schedules_test.csv)
    Returns a predicted quality score (0-100).
    """
    # 2. Preprocess using the saved encoders/scalers
    # Note: is_training=False ensures we don't 'fit' on new data
    X, _, _ = preprocess_data(df_new_schedule, is_training=False)
    
    # 3. Predict
    predictions = model.predict(X)
    
    # 4. Return the mean score for the whole schedule
    return float(predictions.mean())
```
